Reading notes toward visual experiments in hyperbolic geometry, Mostow rigidity, quasiconformal maps, and physical models of negative curvature.

- [Mostow rigidity](books/mostow-rigidity.md)
- [Hyperbolic crochet](books/hyperbolic-crochet.md)

## Status

This repository currently contains reading notes and images. It does not yet contain a Mostow-rigidity visualizer or a numerical implementation of the theorem.

Visual experiments should keep mathematical statements separate from analogies, projections, meshes, and physical models. Link to the original authors and public sources; do not copy copyrighted texts or figures without permission.
