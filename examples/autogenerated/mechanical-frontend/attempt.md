# Mechanical frontend mutation witness

The user requires displayed mathematics to correspond to the semantic state.
The meaningful negative case keeps the live numerical HUD while replacing an
encounter's geometry input by an initialized constant scene. A screenshot
whose numbers change while the object stays fixed must fail.

Values and domains: a valid scene-schema-4 state, a qualified direct ICK host
compiler, the qualified Grease runtime, and explicit EGL/GLES headers and
libraries. The five encounter domains are quotient transport, genus-2 pants,
metric tangent distortion, integer inclusion, and ideal-tetrahedron boundary
transforms. Their mathematical domains remain owned by the existing kernel
headers; this test does not redefine them.

Input/output contract: the shell test takes one absolute or Git-resolved
checkout path and explicit compiler/GL environment. For each named mutant it
produces source, executable, captured images/scenes and a log below the ignored
host build directory. A successful test invocation means every compiled
constant-geometry implementation was rejected by its intended unchanged
geometric witness. A compiler failure or unrelated EGL failure cannot satisfy
that postcondition. Compilation, process execution and files are the effects.

The geometric witness compares the framebuffer region away from numerical
readouts and controls after shared control operations change semantic state.
The normal renderer also requires exact framebuffer reopening from persisted
state. The mutation candidate changes only the relevant drawing function's
scene input. It does not weaken or replace the acceptance code, kernel tests,
expected diagnostics, or the live HUD.

This task is a shell procedure, so Grease is the selected language. It uses
the actual selected ICK compiler on original ICKY sources; no source
normalization, generic compiler substitute, new application runtime or
unqualified Idriç execution is involved.

Attempt 1 is retained as `attempts/1-ambiguous-backslash.grease`. The qualified
Grease runtime rejected the sed replacement literals before any build:
`Ambiguous backslash: add explicit r'' or u'' prefix (OILS-ERR-20)`.
The current candidate supplies explicit raw-string prefixes, preserving the
backslashes needed by sed's replacement syntax. This is an authored syntax
correction, not a missing Grease capability or permission to invoke Bash.

The parent execution binds the current test and sources to its Flexible Pipes,
Kitchen/Ike and source-revision receipts. Current execution results and binary
digests remain in those receipts rather than being promoted from this account.
All evidence is host mathematical/render evidence. Phone installation,
interaction, GPU behavior, persistence and resume require separate physical
acceptance.
