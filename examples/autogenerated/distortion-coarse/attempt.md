# Metric distortion and the integer inclusion

The requested existing mathematical owner is compositional ICKY C. These are
platform-free additions to that owner, not an Idriç execution claim. No new
application runtime or source-normalization fallback is introduced.

## Types and laws fixed before implementation

- A tangent metric is a symmetric positive-definite bilinear form, represented
  by its three binary64 coefficients in an explicitly chosen oriented basis.
- A differential maps the source oriented tangent plane to the target one.
- A successful diagnostic reports two positive singular values in metric
  orthonormal bases, ordered largest first; their ratio is local dilatation.
  Their product is unsigned metric area scaling. The determinant sign records
  orientation separately: a reflection has K = 1 but is anticonformal.
- Invalid numbers, nonpositive-definite metrics, singular differentials and
  numerically unsupported conditioning return distinct error states. A failed
  result contains unavailable values, never a fabricated conformality PASS.
- Circle sampling consumes the same metric normalization as measurement. Its
  source point is on the unit circle in a source orthonormal frame; its image
  is expressed in a target orthonormal frame. This makes a visible ellipse a
  consequence of the semantic differential rather than a hand-drawn proxy.
- The integer inclusion has exact global constants L = 1, A = 0, B = 1/2.
  A finite binary64 witness routine is deliberately restricted to |x| ≤ 2^50;
  the proof in the companion note concerns every real number independently.

Central operations: `measure(differential, source_metric, target_metric)`;
`sample(differential, source_metric, target_metric, angle)`;
`nearest_integer(real)`; `integer_distance(first, second)`. All are pure,
bounded calculations using caller-owned values. The kernels perform no IO.

Independent controls: exact diagonal forms, a rational rotation, the golden
ratio shear spectrum, determinant/trace identities, an off-diagonal metric
coordinate change, orientation reversal, singular/indefinite controls, and
half-integers witnessing the sharp coarse-surjectivity bound.

Implementation and acceptance results are recorded after execution; source
presence is not a numerical or device qualification.
